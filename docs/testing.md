# Как проверять

Принцип владельца: перед показом всё проверять замерами, а на слух финальное слово за ним. Тесты без FL, никаких окон на экране во время его записи.

## Инструменты (`tests\`)
- `test_main.cpp` → `ark_test.exe`: гоняет тюн оффлайн по wav. Пишет стерео float32 и `.f0.csv` (высота по времени).
- `fx_test.cpp` → `fx_test.exe`: гоняет реверб или дилей, источник wav или `impulse`.
- `scripts\*.py` (Python, venv `_работа\venv-ai`; запускать с `-I`):
  - `mix3_eval.py`, `split_gain.py`, `cmp_art.py`: охват и попадание в ноты, сравнение с Auto-Tune Artist.
  - `kitty_match.py`: полосы Mr Kitty против тюна (1–4 кГц, верх), эталон ±0.6 дБ.
  - `fx_ir.py`: RT60 и спектр реверба по импульсу; `fx_voice.py`, `fx_presets.py`: все пресеты на голосе (finite, пик, хвост).
  - `lpc_clicks.py`: щелчки по LPC-остатку (сравнение сухого и обработанного).
  - `build_222.py`, `build_split.py`, `fix_voices.py`: сборка и правка проектов FL для проверок.

## Чек-лист перед выдачей
1. Сборка `build.ps1 -Plugin all` без ошибок, `check_load.py` для каждого `.vst3`.
2. Тюн: охват голоса, скачки больше 100 центов в секунду, щелчки (lpc_clicks) не хуже сухого; стерео (`pan -1/0/1`).
3. Реверб: RT60 по цели, хвост затухает (последняя секунда ниже −100 дБ), корреляция L/R.
4. Дилей: повторы ровно через заданное время, чередование L/R.
5. Пресеты: `fx_presets.py` (ни NaN, ни скачков).
6. Mr Kitty: `kitty_match.py` (полосы ±0.6 дБ от тюна).
7. Интерфейс: снимки `tools/preview*.cpp`, посмотреть глазами.
8. Рендер проекта FL при закрытом FL (`fltools render`) и замеры, если менялась обработка в проекте.
9. Кроссплатформенность: в `src/core` нет платформенных заголовков, новое платформенное за `#if`.

## Типичные находки
- Щелчки: обрезка зерна, непрочищенные буферы, скачки параметров без сглаживания.
- Хвост реверба не затухает: выход индекса за буфер линии.
- Состояние проекта едет: изменён диапазон параметра (нужна миграция).
