# История изменений

## 0.5.2, 17 Nov 2026
- Стрелки пресетов: правая зона клика совпадала не с нарисованной стрелкой, теперь обе стрелки работают, зона шире.

## 0.5.1, 17 Nov 2026
- Пресеты переключаются из окна (убран флаг program change, с ним FL игнорировал смену).
- Latency Mode по умолчанию Clean, Reference 440 Hz.
- Версия и дата релиза показаны в шапке каждого плагина.
- Светлый дизайн смягчён (серый фон вместо белого), звезда убрана.

## 2026-11-17 (версии Vocal 0.4.0, Reverb/Delay 0.2.0)
- Переименование: Arkham → Starz (Starz Vocal, Starz Reverb, Starz Delay), те же UID. Файлы `StarzVocal.vst3` и т.д. Старые `Arkham*.vst3` удаляются при установке.
- Светлый дизайн в стиле STARZ (белый фон, чёрные плашки, оранжевый акцент, острые углы), новая шапка с звездой.
- Кроссплатформенность: DSP отделён в `src/core`, окно за `_WIN32`, `bridge.h`, CMake и workflow для macOS/Windows. На macOS пока без собственного окна.
- Новая структура папки разработки `plugins\starz`, единый скрипт сборки `build\build.ps1`.
- Vocal: стерео вход сохраняется (баланс L/R для wet, dry стерео); компенсация роя (громкость ×(1+0.3·widen), полка 5 кГц), полосы в пределах ±0.6 дБ от Auto-Tune; Voices 1–24; Latency Mode; Stepped; Swarm.
- Reverb и Delay вынесены в два отдельных плагина (были идеей встроенного блока в Vocal), по 8 пресетов; Delay с Sync от темпа хоста.
- Исправлена ошибка линии задержки (выход за буфер, вечный тональный хвост).
- Старое место `_работа\plugin` оставлено как архив, источником правды считать `plugins\starz`.
