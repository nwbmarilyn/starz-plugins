# Очередь улучшений

Правило: каждая задача сразу кроссплатформенная (Windows + macOS), см. `architecture.md`.

## Ближайшее
- Свой интерфейс на macOS (сейчас хостовый список параметров): вариант на VSTGUI из SDK либо Cocoa/CoreGraphics поверх `Bridge`, палитра из `design.md`.
- Первая сборка и проверка на macOS (GitHub Actions или Mac), исправить найденное.
- Оценка пресетов реверба и дилея на слух, правка по значениям владельца (брать из диффа проекта).
- Пресет «Klyukva» целиком (тюн + рой + реверб + дилей) по замерам Pharaoh: строй +23 цента, жёсткие плато (Retune 0), яркий широкий короткий реверб (RT60 около 0.5 с).
- Папка пользовательских пресетов на диске (сейчас только внутренние программы).

## Тюн
- Устойчивость детектора на смеси нескольких голосов; режим мульти-питч (сложно, пока дубли разводим по insert'ам).
- Humanize и Natural Vibrato; точность подтяжки на переходах нот.
- Автоподбор компенсации роя по числу голосов (сейчас константы gMake, gShelf).

## Эффекты
- Режим «tempo-синхронизация» с долями в мс на экране; Tap tempo.
- Реверб: пресеты размеров комнаты (early reflections), режим Shimmer.
- Дилей: фильтры в петле с резонансом, режим Reverse.

## Инфраструктура
- Автотесты в одном скрипте (`tests\run_all.ps1`): прогон чек-листа из `testing.md` с выводом таблицы.
- Версионирование и `changelog.md` при каждой сборке.
